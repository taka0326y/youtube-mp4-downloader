# YouTube MP4 Downloader — Apple Silicon版

M1/M2/M3/M4/M5等のApple Silicon搭載Mac、macOS13以降向けです。

1. ReleasesからYouTube-MP4-Downloader-AppleSilicon.zipをダウンロードして展開。
2. アプリを「アプリケーション」フォルダへ移動。
3. 初回はFinderで開く。開発元を確認できないと表示された場合は、信頼できる配布元か確認のうえ「システム設定 → プライバシーとセキュリティ」の「このまま開く」を使用。

AppleのDeveloper ID署名・公証はしていません。警告は出る可能性があります。Macの保護機能を全体で無効にする必要はありません。企業管理Macで実行を禁止されている場合は管理者に確認してください。

動画URLを1行1本で貼り付け、1080p・720p・360pと保存先を選び「ダウンロード開始」。初期保存先はDownloadsです。選択画質以下で利用可能な最高画質を保存します。バッチの進捗・保存と失敗件数・経過時間を表示。成功を含む完了時に独自の短い音が1回鳴ります。中止・全件失敗・終了時は鳴りません。

ffmpeg・yt-dlp・Node.jsを同梱しており、HomebrewやPythonの追加インストールは不要です。公開動画のみを対象とし、ログイン認証やブラウザのCookieは読み取りません。ログイン必須・非公開・地域制限などで取得できない動画があります。プレイリストを自動展開しないため、個別動画URLを指定してください。YouTubeの変更で将来取得できなくなる可能性があります。

検証: Intel Macからarm64向けにクロスビルドし、アーキテクチャ・動的依存・署名を確認。Apple Silicon実機での起動や動画取得は未確認です。配布元GitHubにソース・依存ライセンス・検証記録を添付しています。
